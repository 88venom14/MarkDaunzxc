# МаркДаун — Заметки с поддержкой Markdown

Приложение для создания и редактирования заметок с поддержкой Markdown и изображений.

## Возможности

- **Редактирование текста** — создание и редактирование заметок
- **Поддержка Markdown** — форматирование текста (заголовки, жирный, курсив, списки, код)
- **Изображения** — вставка картинок в заметки:
  - Рисование от руки
  - Вставка изображений из файлов
- **Просмотр** — отображение заметок с картинками в режиме просмотра
- **Предпросмотр** — просмотр отрендеренного Markdown
- **Сохранение** — все заметки сохраняются в JSON файл

## Запуск приложения

### Вариант 1: Запуск EXE файла (рекомендуется)

1. Перейдите в папку `dist`
2. Запустите файл `MarkDown.exe`

```
c:\project\mardaun\dist\MarkDown.exe
```

### Вариант 2: Запуск из исходного кода

**Требования:**
- Python 3.13 или выше
- Установленные зависимости

**Установка зависимостей:**
```bash
pip install markdown pillow
```

**Запуск:**
```bash
cd c:\project\mardaun
python zalupametki.py
```

## Как пользоваться

### Создание заметки
1. Нажмите кнопку **"Новая заметка"** в левой панели
2. Введите заголовок в поле "Заголовок:"
3. Напишите текст заметки

### Вставка изображения

**Рисование:**
1. Нажмите **"Рисовать"**
2. Нарисуйте что-нибудь в окне рисования
3. Нажмите **"Сохранить и вставить"**

**Вставка из файла:**
1. Нажмите **"Вставить картинку"**
2. Выберите изображение на компьютере
3. Картинка будет скопирована в папку `images` и вставлена в заметку

### Режимы работы

- **Редактировать** — режим редактирования текста (Markdown синтаксис)
- **👁 Просмотр** — режим просмотра с отображением картинок

### Сохранение
Нажмите **"Сохранить"** для сохранения заметки. Все заметки сохраняются в файл `notes.json`.

### Удаление
1. Выберите заметку в списке
2. Нажмите **"Удалить"**

## Markdown синтаксис

В заметках поддерживается Markdown:

```markdown
# Заголовок 1 уровня
## Заголовок 2 уровня

**жирный текст**
*курсив*

- элемент списка
- ещё элемент

`код в строке`

![image](путь/к/картинке.png)
```

## Сборка EXE файла

Для сборки исполняемого файла:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name MarkDown --icon=photo_2026-03-15_22-35-31.ico zalupametki.py
```

Готовый файл появится в папке `dist/`.
